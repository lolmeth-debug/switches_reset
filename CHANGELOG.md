# Changelog

Все значимые изменения в этом проекте документируются в этом файле.

Формат дат: `ДД.ММ.ГГГГ`

## [1.08043] — 05.08.2026

### 🐛 Исправлено

- **Парсинг Boot Version у QTECH** — удалена попытка парсинга `Boot Version` в процедуре `ver_def_qtech`, так как вывод часто разбивался на несколько строк, вызывая ошибку определения. Так как эта версия не критична для процесса, шаг парсинга пропущен для ускорения и повышения надежности сброса.

---

## [1.08042] — 04.08.2026

### 🐛 Исправлено

- **Лог сброса: модель и MAC-адрес теперь корректны** — `switch_data['vendor']`, `['model']`, `['mac']` теперь заполняются из реальных данных `show switch` / `show ver` внутри каждой функции сброса (`ver_def3526`, `ver_def3200`, `ver_def1210MEA1`, `ver_def_snr`, `ver_def_qtech`). Раньше данные заполнялись только в функциях печати `prn_stick_*`, которые вызываются только при режиме «Сброс+наклейка», поэтому при обычном сбросе в логе были пустые вендор, модель и MAC.
- **Лог «Наклейка» для кнопки «Печать QR подключенного коммутатора»** — добавлена запись в лог для режима печати без сброса (D-Link, SNR, QTECH).

## [1.08041] — 04.08.2026

### 🐛 Исправлено

- **Лог версии прошивки для всех моделей** — `switch_data['fw']` теперь заполняется для всех вендоров (SNR, QTECH, D-Link 1210 ME/A1, 3200, 3526) и при печати наклейки без сброса. Раньше версия прошивки записывалась в `switches_reset.log` только для D-Link 3200 и 3526.
- **Ошибка `name 'show_ver_buf' is not defined`** — в `ver_def_snr` переменная `show_ver_buf` теперь корректно инициализируется из `data_raw['buf']` перед использованием.

## [1.08040] — 04.08.2026

### 🐛 Исправлено

- **Автопереключение скорости COM (D-Link 1210)** — после переключения скорости и совпадения раннего паттерна (`Uncompressing`) программа больше не закрывает COM-порт. Буфер передаётся в `ver_defDlink` через параметр `pre_buf`, чтобы не терять данные, уже находящиеся в COM-буфере. Если коммутатор не опознан — скорость фиксируется, пользователю предлагается перезагрузить и перезапустить сброс.

### ✨ Добавлено

- **Лог сброса коммутаторов** — создан файл `switches_reset.log`, в который записываются итоговые данные: дата/время, действие (сброс/сброс+наклейка), вендор, модель, MAC-адрес, версия прошивки.
- **Данные коммутатора** — глобальная переменная `switch_data` заполняется в `prn_stick_dlink`, `prn_stick_snr`, `prn_stick_qtech` и в процедурах сброса D-Link (версия прошивки из `show switch`).

### 🗑️ Убрано

- **Надпись "СБРОШЕН К ЗАВОДСКИМ"** — удалена из `print_log` для D-Link 3200 и 1210 (оставлена только на прогресс-баре).

## [1.08039] — 04.08.2026

### 🐛 Исправлено

- **Автопереключение скорости COM** — после переключения скорости (например, 115200→9600) при автоопределении коммутатора, если совпал ранний паттерн загрузки (`Uncompressing`), программа больше не закрывает COM-порт. Вместо этого:
  - Буфер, прочитанный после переключения, передаётся в процедуру сброса (`ver_defDlink`), чтобы не терять данные ("Kernel Image", "100%" и т.д.), которые уже в COM-буфере.
  - Если коммутатор опознан — процедура сброса продолжается.
  - Если не опознан — скорость фиксируется, пользователю предлагается перезагрузить и перезапустить сброс на правильной скорости.

## [1.08034] — 03.08.2026

### ✅ Исправлено

- **Ложное определение SNR как D-Link** — убран `"Uncompressing"` из списка паттернов D-Link в `reset_whatswitch()` и `guess_vendor_from_buf()`. Это общее сообщение Linux-ядра (`Uncompressing Kernel Image...`), которое есть у всех коммутаторов на Linux (SNR, QTECH, D-Link). Из-за того, что проверка D-Link шла первой, SNR-коммутаторы ошибочно определялись как D-Link.
- **Добавлены SNR-специфичные паттерны** — `"Bootrom version"` и `"nos.img"` добавлены в список обнаружения SNR в `reset_whatswitch()`, `read_until_autospeed()` и `guess_vendor_from_buf()`. Теперь SNR 2960 корректно распознаётся на раннем этапе вывода загрузчика.

## [1.08033] — 03.08.2026

### ✅ Исправлено

- **Автоопределение и печать наклейки подключенного коммутатора (SNR/QTECH)** — исправлен баг, при котором процедура `check_login_dlink` возвращала `True` без проверки успешности авторизации (наличия `#` в буфере). Из-за этого SNR-коммутатор ошибочно распознавался как D-Link, что приводило к отправке неверных команд и сбою авторизации.
- **Таймауты при автоопределении** — убраны вызовы `check_timeout()` из процедур проверки логина (`check_login_dlink`, `check_login_snr`, `check_loginpass_snr`), чтобы таймаут при опросе одного вендора не прерывал всю процедуру автоопределения и не взводил глобальные стоп-флаги.
- **Оптимизация опроса** — в `check_login_dlink` добавлен быстрый выход при обнаружении приглашений `sername:` или `assword:`, что исключает лишнее ожидание таймаута.

### ✨ Улучшено

- **Компактный лог** — скрыты из видимого лога сообщения о печати наклеек (`печать наклейки SNR`, `обнаружен S2960...`, `Печать наклейки D-Link/SNR/QTECH`).
- **Сохранение статуса прогресс-бара** — сообщение об успешном сбросе ("СБРОШЕН К ЗАВОДСКИМ") теперь не исчезает из прогресс-бара по завершении процедуры и остаётся видимым до начала новой операции, перечитывания портов или печати наклейки.
- **Очистка прогресс-бара** — добавлена очистка текста прогресс-бара при вызове авто-печати наклейки и при очистке лога.

## [1.08032] — 03.08.2026

### ✅ Добавлено

- **Определение версий прошивок** — функция `print_firmware_info()` парсит версию из буфера и выводит в лог с подсветкой: 🟢 зелёный (актуальная), 🟡 жёлтый (можно обновить / нет в базе).
- **База актуальных прошивок в файле `actual_firmwares.txt`** — версии читаются из внешнего файла (формат `vendor|model|version`), редактируется без изменения кода.
- **Парсинг QTECH** — регулярка `Firmware Version[.\s]+([\d.]+)` из буфера после `sending DISCOVER package` (учитывает точку вместо пробела: `Version.238`).
- **Парсинг SNR** — регулярка `Version\s+(?:software\s+)?(\S+)` из `show ver`.
- **Парсинг D-Link** — `_parse_version_tuple()` устойчив к суффиксам вроде `B007D`.
- **Текст обратного отсчёта в прогресс-баре** — `Ожидается перезагрузка устройства... N сек.` отображается поверх прогресс-бара через `Label` вместо `print_log`.

### ✨ Улучшено

- **Компактный лог** — убраны из видимого лога: `Выполняем определение коммутатора`, `COM-порт открыт на скорости`, сообщения об остановке/закрытии порта/стоп-флагах. Объединены `Устройство не распознано` и `Сброс не удался` в одно сообщение в прогресс-баре.
- **Прогресс-бар при отмене** — при отмене/ошибке сброса прогресс-бар сразу сбрасывается в 0% без скачка на 100%.
- **Очистка текста прогресс-бара** — при нажатии "Перечитать порты" текст прогресс-бара очищается.

### 🐛 Исправлено

- **Автофиксация скорости COM при автоцикле** — при автоматическом определении скорости добавлены `saved_autospeed` и `saved_autospeed_valid`. Найденная скорость сохраняется и используется в следующем цикле сброса, затем сбрасывается для возобновления автоопределения.
- **Принудительное закрытие COM-порта и очистка буфера** — в начале `do_reset_whatswitch` гарантированно закрывается старый порт и очищаются входной/выходной буфера, чтобы данные предыдущего цикла не попадали в автоопределение.
- **Конфиг не отправляется для D-Link** — `upload_config()` вызывается только для SNR и QTECH (проверка по `what_print["SNR"]` / `what_print["QTECH"]`). Для D-Link конфиг больше не заливается.
- **Сохранение данных отладки между циклами** — `clear_text()` больше не очищает debug-окно, автоочистка при переполнении убрана из `_drain_debug_queue()`. Очистка происходит только при закрытии программы или нажатии кнопки.
- **Кнопка «🗑 Очистить отладку»** — добавлена для ручной очистки окна отладки в любой момент.
